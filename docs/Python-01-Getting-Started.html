9  The first steps in Python

9.1 Positron for the first time

Positron is not only an IDE for R, but also for Python. For installation just follow the instructions on https://positron.posit.co/download.html

In addition, you need a Python installation. Positron detects installed Python versions automatically and lets you pick one as interpreter (the button in the upper right corner of the window). A good practice is to create a virtual environment for each project, i.e., a folder (usually called .venv) that contains the Python interpreter together with all packages you install for this project. In Positron you can create one via the command palette (Ctrl+Shift+P) and the command Python: Create Environment.

When you open Positron, its window is typically split into the following areas:

  1. The editor showing your script file, which is an ordinary text file with suffix .py. For instance, yourFavoritFileName.py. This file contains your code.
  2. The Session pane showing all objects (variables) we have defined in the environment.
  3. The Plots and Help panes showing plots and help files.
  4. The Console, which allows you to type commands and display results.
  5. The Explorer (left) showing the files in your current project folder.

Some other terms that will be useful:

  • Working directory: The file-directory you are working in. Useful commands: with os.getcwd() you get the location of your current working directory and os.chdir() allows you to set a new location for it (both functions are part of the module os, which you load with import os). This is very useful when you would like to load or save several files. You can just set your working directory globally and all files can be loaded or will be saved into this directory.
  • Workspace (namespace): This is where all objects you use (e.g., data, matrices, vectors, variables, functions, etc.) are stored during your session. Useful commands in the Positron console: %who shows all variables in our current workspace and %reset -f deletes all elements in our current workspace. It is also possible to remove only some objects with del object1, object2.

9.2 Simple calculations

We start with a very basic calculation. Let’s type 1+1 into the console window and press enter. We get

1+1 # first calculation
2

i.e. the result of the calculation is returned.

Note that everything that is written after the #-sign is ignored by Python, which is very useful to comment your code. The second window above shows the output.

Let’s consider a second calculation

1+2+3+ # second calculation
  Cell In[2], line 1
    1+2+3+ # second calculation
           ^
SyntaxError: invalid syntax

This calculation ended with an error. The reason is that the command can only processed if entered correctly.

1+2+3+4 # second calculation
10

A similar thing happens when parentheses are not closed.

2*(2+3
  Cell In[4], line 1
    2*(2+3
          ^
SyntaxError: incomplete input

It will be helpful to use a script file, such as yourFavoritFileName.py, to store your Python commands. Otherwise, you would have to type your code again when an error occurred. You can send single lines or marked regions of your Python code to the console by pressing the keys STRG+ENTER.

9.3 Assigments and matrix algebra

The assignment operator will be your most often used tool. Here is an example where a scalar variable is created:

x = 9
x
9
x+1
10

Note: If you run several lines at once (e.g., a code block), Python only shows the result of the last line. If you want to see several results, use the print() function:

x = 9
print(x)
print(x+1)
9
10

In Python, assignments are always done with the = operator (there is no <- as in R). More on Python style recommendations can be found in the PEP 8 style guide.

We consider now a vector, an object you will use frequently. Python itself does not have vectors and matrices in the mathematical sense. They are provided by the package NumPy, which we load (under the usual short name np) with

import numpy as np

A vector is then created with np.array():

z = np.array([1,3,5,6])
z
array([1, 3, 5, 6])

As discussed, %who states the content of the workspace, whereas %reset -f deletes the workspace.

%who
np   x   z   
%reset -f
%who
Interactive namespace is empty.

Note that %reset -f also removed the NumPy package from the workspace, so we have to load it again.

import numpy as np

In the next step we will consider some vector multiplication. There are three different ways to multiply a vector, namely element by element, using the inner product, or using the outer product. Element by element gives you a vector of the same dimension.

z = np.array([1,3,5,6])
z*z                #multiplication element by element
array([ 1,  9, 25, 36])

The attribute .T gives the transpose of a vector (or matrix). It is therefore tempting to calculate the inner product as

z.T*z                #multiplication inner product?
array([ 1,  9, 25, 36])

but this does not give the desired answer. (A one-dimensional NumPy array is neither a row nor a column vector, so transposing it does not change anything.) Instead, you have to use the matrix multiplication operator @

z = np.array([1,3,5,6])
z @ z                #multiplication inner product
np.int64(71)

The output np.int64(71) simply means: the number 71, stored as a NumPy integer. (With print(z @ z) you would only see 71.) Note that, in contrast to R, NumPy stores zTz as a number and not as a matrix.

type(z @ z)
numpy.int64
type(z)
numpy.ndarray

Finally, we have the outer product that gives us a matrix

z = np.array([1,3,5,6])
np.outer(z, z)                #multiplication outer product
array([[ 1,  3,  5,  6],
       [ 3,  9, 15, 18],
       [ 5, 15, 25, 30],
       [ 6, 18, 30, 36]])

In general, be very careful with @ versus *. They are often both feasible, but yield different results!

You can also multiply a vector with a scalar:

z*4
array([ 4, 12, 20, 24])

A strength of NumPy is that operations can be conducted for each element of the vector in one statement

print(z**2)
print(np.log(z))
print((z-np.mean(z))/np.std(z, ddof=1))
[ 1  9 25 36]
[0.         1.09861229 1.60943791 1.79175947]
[-1.24021595 -0.33824071  0.56373452  1.01472214]

Note: np.std() divides by \(n\) by default. With the argument ddof=1 it divides by \(n-1\), as R’s sd() does.

So far, we have seen the function np.array() that can be used to combine objects. All function calls use the same general notation: a function name is always followed by round parentheses. Sometimes, the parentheses include arguments, such as

z = np.arange(start = 1, stop = 6, step = 1)
z
array([1, 2, 3, 4, 5])

Note that the stop value is not included.

With square brackets you can access particular elements, such as

z[0:3]                  #refer to particular elements
array([1, 2, 3])

Attention: In Python, counting starts at 0, i.e., z[0] is the first element of z. Moreover, z[0:3] includes the elements at positions 0, 1, and 2, but not the element at position 3.

We will next define a matrix and perform matrix-vector multiplication.

M = np.arange(1, 10).reshape((3,3), order = "F")    # define matrix M (filled column by column, as in R)
print(M)
print(M.shape)                                     # dimension of M
print(z.shape)                                     # dimension of z: (5,) means one-dimensional with 5 elements
print(len(z))                                      # number of elements of z
[[1 4 7]
 [2 5 8]
 [3 6 9]]
(3, 3)
(5,)
5

Element-by-element multiplication for M is given by

M * M
array([[ 1, 16, 49],
       [ 4, 25, 64],
       [ 9, 36, 81]])

Standard matrix multiplication is again done using @ such as

M @ M
array([[ 30,  66, 102],
       [ 36,  81, 126],
       [ 42,  96, 150]])
M.T @ M
array([[ 14,  32,  50],
       [ 32,  77, 122],
       [ 50, 122, 194]])

If matrices and vectors have suitable dimensions, you can multiply them as follows:

M @ z[0:3]
array([30, 36, 42])

Similar to before, with square brackets you can access particular elements, such as

print(M[:,2])                 # state the third column of M
print(M[2,2])                 # state element in the third column and third row of M
[7 8 9]
9

Here are some more examples:

M[:,0]                 # first column of M
M[2,2]                 # element in the third column and third row of M
z[[0,3]]               # first and fourth element of z

Logical statements are also very useful. For example, if you want to know which elements in the first column of matrix M are strictly greater than 2:

# See which elements:
print(M[:,0]>2)
# and extract the elements
print(M[M[:,0]>2,0])
[False False  True]
[3]

Note: Logical operations return so-called boolean objects, i.e., either a True or a False. For instance, if we ask Python whether 1>2 we get the answer False.

9.4 Operators

We have already seen basic arithmetic operations such as

+, -, *, /

Decimals are declared with a “.”, not a comma

1.8 not 1,8

Exponents are declared with **, i.e. \(2^3\) is written as

2**3

Attention: In contrast to R, 2^3 does not compute \(2^3\) in Python (^ is the “bitwise exclusive or” operator).

For mathematical calculations, only parentheses () can be used.

Frequently used mathematical functions are (most of them are provided by NumPy)

np.sqrt()                # square root
np.exp()                 # exponential function
np.log()                 # nat.  Logarithm
np.log10()               # Logarithm with Base 10
abs()                    # absolute value
round(...,x)             # rounding to x decimals.
np.pi
np.e                     # Eulers number
np.sin(),np.cos(),np.tan() # trigonemetric functions
np.min(), np.max()       # returns the lowest/highest value of a vector/matrix

As a few examples enter the following calculations and make sure to understand the commands:

1.8+2
1.8-2
1.8*2
1.8/2
2+2*3
(2+2)*3
2**3
8**(1/3)
3**2
9**0.5
2**2*2+2
2**(2*((0.2+0.3)*(1+2)))+4
np.sqrt(2)
np.exp(1)
np.exp(2)
np.log(7.389056)
np.log(np.exp(3))
np.log10(100)
abs(1.8-2)
round(np.sqrt(2),2)
round(np.sqrt(2),4)
np.pi
np.sin(np.pi/2)
np.sin(np.pi)
np.tan(np.pi)
x=2+3j     # complex numbers: Python uses j instead of i
y=4+1j
x
y
x+y
x*y

Attention:

1.2246467991473532e-16

is interpreted as \(1.2246467991473532 \times 10^{-16}\). This is often exactly zero, but for internal memory purposes (Python uses double-precision floating-point numbers and therefore only has up to 16 decimals), can be a rounding mistake.

9.5 Further data objects

Besides classical data objects such as scalars, vectors, and matrices there are three further data objects that we will use frequently:

  1. The array: A NumPy array can have more than two dimensions. Here is an example of a 2×2×2-dimensional array
myFirst_Array = np.arange(1, 9).reshape((2,2,2), order = "F")
  1. The dictionary: In dicts you can organize different kinds of data (this is the counterpart of R’s list). E.g., consider the following example:
myFirst_Dict = {"Some_Numbers": [66, 76, 55, 12, 4, 66, 8, 99],
                "Animals"     : ["Rabbit", "Cat", "Elefant"],
                "My_Series"   : list(range(30, 0, -1))}

Python also has a data object called list, e.g., ["Rabbit", "Cat", "Elefant"], which is simply an ordered collection of arbitrary objects.

  1. The data frame: Data frames are provided by the package pandas. A DataFrame is designed to store data, where each column can have a different type, but all columns have the same number of rows:
import pandas as pd

myFirst_Dataframe = pd.DataFrame({"Credit_Default"  : [ 0, 0, 1, 0, 1, 1],
                                  "Age"             : [35,41,55,36,44,26],
                                  "Loan_in_1000_EUR": [55,65,23,12,98,76]})

9.6 Python help

There exist help files for all commands in Python. For example consider the help file of the function np.sum(). You can access the help file with

help(np.sum)

or, in the Positron console, with ?np.sum.

The file usually contains the categories: Parameters, Returns, See Also, Notes and Examples.

After the general description follows the syntax of the command. This usually indicates which (optional) arguments the command allows. Missing values are denoted by np.nan (“not a number”). If a vector contains missing values, np.sum() returns nan. The function np.nansum() ignores missing values.

x = np.array([1,2,np.nan,4,5])
print(x)
print(np.sum(x))
print(np.nansum(x))
[ 1.  2. nan  4.  5.]
nan
12.0

Note that the behavior of pandas is different: Here, missing values are ignored by default (argument skipna=True).

pd.Series(x).sum()
np.float64(12.0)

9.7 Python packages

There are tons of Python packages that are useful for different aspects of data analysis. Some packages that you will use all the time are numpy (vectors and matrices), pandas (data frames), matplotlib and seaborn (plots), and scipy and statsmodels (statistics). You can install packages in the terminal with pip install packagename, or directly in the Positron console with %pip install packagename. In order to use the package type import packagename, or, with a short name, import packagename as short_name. The package has to be installed only once (per virtual environment), but you have to load the package with import every time you want to use it.
